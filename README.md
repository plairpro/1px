# 1px

https://plairpro.github.io/1px/

Общее полотно 1920 × 1080. Клетки 10 × 10. Один аккаунт — один вклад.

`index.html` перенаправляет на работающий проект. Сервер, вход через ChatGPT и общая база D1 размещены на Sites; GitHub Pages не выполняет серверные API.

`1px-source.zip` содержит полный исходный код текущей версии, схему базы, миграции и зависимости (package-lock.json). Секреты, пользовательские данные и node_modules в архив не включены.

Разработка после распаковки: Node.js 22+, `npm ci`, `npm run dev`. Сервер публикуется через Sites. GitHub Pages публикует корень ветки main.
